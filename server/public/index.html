O microfone transcreve sua voz diretamente para a caixa de texto do chat. A resposta pode ser lida ou ouvida individualmente pelo botão de áudio.

  • ✓ Ditado preciso direto no chat
  • ✓ Botão de reprodução de áudio em cada mensagem
  • ✓ Ideal para mensagens longas e revisões antes do envio
